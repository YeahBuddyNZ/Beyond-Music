# 0002: The copyright lines are code, not settings

Accepted, 26/10/2026. Kyle: "Just make sure that you understand the law and I will run it past."

## Decision

The lines in `docs/law.md` are built into the code with no switch to turn them off: the server answers the house
network only; there's no disc ripping beyond audio CDs and no decryption; no torrents, indexers or sharing-site
downloads; no lyrics; nothing anybody plays leaves the box; and every album copied from a CD has *I sold or gave away
this CD*, which deletes our copies and hides the rest.

## Why

New Zealand's format shifting exception (Copyright Act 1994, s 81A) is narrow: sound recordings the household owns,
for the household, while it still owns the original. Breaking copy protection is a separate wrong (s 226A and on).
A product people install for their family shouldn't be one setting away from crossing those lines.
